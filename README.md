# Mini-Dashboard Projesi 🚀

Bu proje, Git üzerinde ekip calismasi, modüler kod gelistirme ve **Merge Conflict (Cakisma)** yönetimi becerilerini pekistirmek amaciyla hazirlanmistir.
<br>
## 👥 Proje Ekibi ve Roller

| Ad Soyad | Rol | Sorumluluk |
| :--- | :--- | :--- |
| **Zühre Özen** | Ögrenci A | Entegrasyon, `weather.py` ve Final Kontrol |
| **Aynur Altintas** | Ögrenci B | `news.py` ve Cakisma (Conflict) Cözümü |

<br>

---
## 📝 Ödev Deneyimlerimiz

Ödev kapsaminda bilerek olusturulan cakisma (conflict) sürecindeki deneyimlerimiz su sekildedir:

* **Ögrenci A (Zühre):** "Arkadasimin main.py üzerindeki cakismayi manuel olarak cözmesinin ardindan yaptigim git pull islemiyle, iki farkli modülü sorunsuz bir sekilde yerel bilgisayarimda birlestirmis oldum; bu sürec Git'in versiyon kontrolü ve ekip senkronizasyonundaki önemini görmemi sagladi."

* **Ögrenci B (Aynur):** "Cakisan kodlari manuel olarak birlestirip sorunu cözmek, versiyon kontrol sistemlerinin calisma mantigini kavramami sagladi."

<br>

---
## 🏁 Sonuc
Proje sonunda her iki ögrenci de Git terminal komutlarini kullanarak basarili bir is akisi tamamlamistir. Commit gecmisinde **Merge Commit** ve **Final Touch** kayitlari mevcuttur.
